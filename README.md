# Motion Detection Alarm System

## Overview

This project is a Motion Detection Alarm System using Arduino UNO and a PIR Motion Sensor. The system detects movement and activates an LED and buzzer as an alert.

---

## Components Used

* Arduino UNO
* PIR Motion Sensor
* LED
* Buzzer
* Breadboard
* Jumper Wires

---

## Working

The PIR sensor detects human motion and sends a signal to the Arduino. The Arduino then turns ON the LED and buzzer.

---

## Applications

* Home Security
* Intruder Detection
* Smart Surveillance
